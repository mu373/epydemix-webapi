# SIS

<EndpointSelector />

The Susceptible-Infected-Susceptible model. Individuals return to the susceptible state after recovery, with no lasting immunity.

## Compartments

- **Susceptible**: individuals who can be infected
- **Infected**: individuals who are currently infectious

## Transitions

- **Susceptible &rarr; Infected**: mediated by `transmission_rate` and the number of Infected individuals
- **Infected &rarr; Susceptible**: spontaneous at `recovery_rate`

## Default parameters

| Parameter | Default | Description |
|---|---|---|
| `transmission_rate` | 0.3 | Rate at which susceptible individuals become infected through contact with infectious individuals |
| `recovery_rate` | 0.1 | Rate at which infected individuals recover and return to the susceptible state (1 / infectious period in days) |
