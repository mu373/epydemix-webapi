# SIR

<EndpointSelector />

The Susceptible-Infected-Recovered model. A basic epidemic model where recovered individuals gain permanent immunity.

## Compartments

- **Susceptible**: individuals who can be infected
- **Infected**: individuals who are currently infectious
- **Recovered**: individuals who have recovered and are immune

## Transitions

- **Susceptible &rarr; Infected**: mediated by `transmission_rate` and the number of Infected individuals
- **Infected &rarr; Recovered**: spontaneous at `recovery_rate`

## Default parameters

| Parameter | Default | Description |
|---|---|---|
| `transmission_rate` | 0.3 | Rate at which susceptible individuals become infected through contact with infectious individuals |
| `recovery_rate` | 0.1 | Rate at which infected individuals recover (1 / infectious period in days) |
